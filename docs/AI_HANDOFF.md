# 让另一个 AI 接手

有项目访问权限时，可以直接发一句：

> 请读 research/STATUS.md 和 research/PREFERENCES.md，核对当前产物，接着做唯一下一步。需要复核哪个结论，再沿链接读它的原始证据。

只能聊天时，先导出快照，检查分享范围后交给下一位：

```bash
python3 tools/export_handoff.py --project /path/to/project --output /path/to/handoff.md
```

采用精简接力卡的项目会导出状态与偏好两份全文，以及 Git 状态和文件哈希。旧项目沿用原有全量记录清单；任何项目都可以用 `--full` 显式导出完整允许列表。导出保留原文，长历史放在独立的证据和决策文档。

需要核查一个新结果时，只追加该实验卡与相关结果。有多位协作者时确认当前写入者和在跑的任务，交出前用一句话写清下一步由谁接。快照仅含研究记录，路径相对原始项目，权限及可访问数据应在交接时核实。
